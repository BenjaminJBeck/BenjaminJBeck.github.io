Pixelator

Convert images into Minecraft-style pixel textures

× 16 pixels

Common sizes: 16×16 (Minecraft default), 32×32, 48×48, 64×64

How to Use

  1. 1. Set your desired pixel size (default 16×16 for Minecraft textures)
  2. 2. Upload or paste images into the Input Images area
  3. 3. Click "CONVERT TO PIXELS" to pixelate your images
  4. 4. Block Textures: Images without transparency will be cropped to square and pixelated
  5. 5. Item Textures: Transparent images will be scaled, rotated slightly, and centered with padding
  6. 6. Use "Name Images" to name each image, then download all as a zip
  7. 7. Double-click any image to view it at full size
  8. 8. Select images (single click) and press Delete to remove them
